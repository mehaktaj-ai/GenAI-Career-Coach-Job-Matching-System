
# 🚀 GenAI Career Coach & Job Matching System

An AI-powered Career Coach and Job Matching System built using the MERN Stack and Google Gemini AI.

## ✨ Features

- AI Career Guidance
- Resume Analysis
- AI Job Matching
- Student Dashboard
- Recruiter Dashboard
- Admin Dashboard
- Secure JWT Authentication
- MongoDB Database

## 🛠️ Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Google Gemini AI
- JWT Authentication

## 📂 Project Structure

```
backend/
frontend/
README.md
```

## ▶️ Installation

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
